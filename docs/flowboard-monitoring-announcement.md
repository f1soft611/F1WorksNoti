# [신규 기능] 모니터링 화면이 추가되었습니다

운영 중인 웹서버 상태를 빠르게 확인하고, 이상 징후에 더 빠르게 대응할 수 있도록 모니터링 화면을 추가했습니다.

## 주요 기능

- 웹서버 상태를 화면에서 즉시 확인할 수 있습니다. (UP / DOWN)
- 자동 갱신으로 주기적으로 상태를 점검합니다. (기본 10분)
- 전체 체크 버튼으로 필요할 때 즉시 수동 점검할 수 있습니다.
- 서버 상태가 변경되면 등록된 담당자에게 알림이 전송됩니다.

## 사용 방법

1. `/monitor` 경로로 접속합니다.
2. 자동 갱신이 활성화되어 있는지 확인합니다.
3. 즉시 점검이 필요하면 전체 체크를 실행합니다.
4. 상태 배지와 마지막 체크 시간을 확인합니다.

## 기대 효과

- 장애 인지 시간을 줄이고 초기 대응 속도를 높일 수 있습니다.
- 운영 점검 절차를 단순화하고 반복 점검 부담을 줄일 수 있습니다.

## 참고

- 기본 헬스체크는 응답 가능 여부 중심으로 동작합니다.

## 예정 사항

- VPN 접속을 통해 확인 가능한 운영서버는 모니터링 대상에 순차적으로 추가할 예정입니다.
